## เมนู Unity: Tools ▸ Thai Boba Shop
1. **Create Cup + Customer Prefabs** → `Assets/Prefabs/ThaiBoba/`
2. **Build Street Set In Current Scene** วางถนน/ร้าน/สถานีทั้งหมด + ระบบ ลงในซีนปัจจุบัน (แล้วกด Bake ที่ NavMeshSurface)
3. **Create HUD Canvas** สร้าง UI ทั้งหมด (เงิน, ดาว, คอมโบ, ออเดอร์, ภารกิจ, สรุปปิดร้าน, ปุ่มสั่งของ/อัปเกรด)
4. **Setup Thai Font** สร้าง TMP font จาก `Assets/Fonts/Thai/Sarabun-SemiBold.ttf` (OFL) ตั้งเป็น fallback และเปิด `mark`/`mkmk` ให้สระ-วรรณยุกต์ซ้อนกันถูกต้อง (เมนู 2/3 เรียกให้อัตโนมัติ)
- **Build Full Demo Scene** สร้าง `Assets/Scenes/ThaiBobaStreet.unity` พร้อมเล่น

## เมนูและการบันทึก
- เมนูหลัก (กล้องเลื่อนดูถนนเป็นฉากหลัง): เล่นต่อ · เริ่มเกมใหม่ (กดสองครั้งยืนยันลบเซฟ) · โหลดวันที่บันทึกไว้ · ตั้งค่า · ออก
- หยุดเกม (Esc / ปุ่มมุมขวาบน): เล่นต่อ · บันทึก · โหลดวัน · ตั้งค่า · กลับเมนูหลัก
- ตั้งค่า: เสียงทั้งหมด/เพลง/เอฟเฟกต์, ความไวเมาส์, การควบคุม (อัตโนมัติ/จอสัมผัส/PC), กราฟิก (ต่ำ/กลาง/สูง), เต็มจอ
- เซฟรายวัน: บันทึกอัตโนมัติตอนกด "เปิดร้านวันถัดไป" เป็นไฟล์แยกต่อวัน (`saves/day_###.json` ใน persistentDataPath, เก็บ 30 วันล่าสุด) โหลดย้อนวันไหนก็ได้

## ตึกและบรรยากาศ
- ตึกแถว 8 แบบ: ร้านชานม, ข้าวมันไก่ (มีโต๊ะ+หม้อมีไอ), ร้านขายยา (ไม้กางเขนนีออนเขียว), มินิมาร์ท 24 ชม., ร้านเสริมสวย, ซ่อมมือถือ, กาแฟโบราณ, ตึกปิด (ให้เช่า/ร้านทอง) — 2–3 ชั้น มีระเบียง ผ้าตาก ถังน้ำบนดาดฟ้า จานดาวเทียม
- ถนนสองฝั่งเต็ม ±40 ม., คอนโด/อพาร์ทเม้นท์ด้านหลัง, ตึกปิดหัวท้ายถนน, พื้นรองทั้งฉาก — มองไปทางไหนไม่เห็นช่องว่าง
- เสาไฟฟ้าพร้อมสายไฟพันกันทุก 8 ม. ต่อกันยาวสุดซอยทั้งสองฝั่งถนน, ไฟประดับข้ามถนน, เสาไฟถนน (ติดเองตอน 18:00 ด้วย `NightLights`), ต้นไม้, แผงขายข้าวแกง
- NPC เดินแค่ทางเท้าฝั่งร้าน: ถนน พื้นรอง และฝั่งตรงข้ามมี `NavMeshModifier` ตัดออกจาก NavMesh

## กลางวัน / กลางคืน
- `DayNightCycle` (อยู่ที่ Sun) คำนวณตำแหน่งดวงอาทิตย์จากนาฬิกา `TimeCyc`: ขึ้น 06:00 ทางทิศตะวันออก เที่ยงอยู่กลางฟ้า ตก ~18:30 แสงส้ม แล้วเป็นแสงจันทร์สีฟ้าจางๆ
- ปรับแสงรอบข้าง สีหมอก และความสว่างท้องฟ้าตามเวลา, เสาไฟติด 18:00 (`NightLights`)
- วันฝนตกจะครึ้ม มืดลง หมอกหนาขึ้นเอง
- `TimeCyc.SetTime(ชม., นาที)` ใช้กระโดดเวลาเพื่อทดสอบได้

## สภาพอากาศและฤดูกาล
- `WeatherSystem` (อยู่ที่ GameSystems): ฤดูเปลี่ยนทุก 10 วันในเกม **ร้อน → ฝน → หนาว** โอกาสฝน 20% / 75% / 8%
- แต่ละวันวางตารางเอง: ฟ้าครึ้มก่อนราว 1 ชม. → ฝนค่อยๆ หนัก → ซา → หยุด แล้วถนนค่อยๆ แห้ง (ฤดูฝนตกนานกว่า และอาจมีพายุ)
- อีเวนต์ "ฝนตกหนัก" ทำให้ฝนตกเกือบทั้งวัน
- พายุ: ฟ้าแลบเป็นระยะ (แสงวาบ + ท้องฟ้า/เมฆสว่างวาบ) ตามด้วยเสียงฟ้าร้อง
- `CloudLayer`: เมฆลอยตามลม จำนวนและสีเทาเพิ่มตามความครึ้ม
- `WetSurfaces`: ถนน/ทางเท้าเข้มขึ้นและมันวาวสะท้อนแสงไฟ มีแอ่งน้ำขยายขึ้นตอนเปียก
- `NPCWeather`: คนเดินถนนกางร่ม (สุ่มสี) ส่วนคนไม่มีร่มจะเดินเร็วขึ้นหนีฝน
- ฝนตก ลูกค้ามากขึ้นสูงสุด 1.8 เท่า (เข้ามาหลบฝน) และสั่ง "ร้อน (ไม่ใส่น้ำแข็ง)" บ่อยขึ้น, ฤดูหนาวก็เช่นกัน, ฤดูร้อนเกือบทุกแก้วใส่น้ำแข็ง
- HUD มุมขวาบนแสดง "ฤดู · สภาพฟ้า" พร้อมไอคอน (วาดใน Illustrator)
- ทดสอบ/ดีบัก: `WeatherSystem.Instance.Force(ฝน 0..1, ความเปียก 0..1, พายุ)` และ `Force(-1, -1, false)` เพื่อกลับไปใช้ตาราง

## Effect
- ไอน้ำจากหม้อไข่มุก/ร้านข้าวมันไก่/แผงอาหาร, ควันท่อรถ, ประกายเหรียญตอนเสิร์ฟ, คอนเฟตติตอนคอมโบ ≥3 และเลเวลอัป (`ShopFX`)
- ฝนตก + น้ำกระเซ็นบนถนน ควบคุมโดย `WeatherSystem`, น้ำสาดในวันสงกรานต์ (`DailyEventSystem`)
- Post-processing: Bloom ให้ป้ายนีออน/ไฟประดับเรือง, Tonemapping, สีสดขึ้น, Vignette และหมอกควันเมือง

## รถบนถนน
- สุดถนนทั้งสองฝั่งเป็นสามแยก มีถนนเลี้ยวซ้าย/ขวา และอุโมงค์มืดๆ (`SM_TunnelPortal`) ที่รถวิ่งหายเข้าไป/โผล่ออกมา
- รถวิ่งตามเส้นทาง (`TrafficRoute`) 12 เส้น: ออกจากอุโมงค์ → เลี้ยวเข้าซอย → ผ่านหน้าร้าน → เลี้ยวซ้ายหรือขวา → เข้าอุโมงค์ ชะลอตอนเลี้ยว
- `TrafficSpawner` + `TrafficCar`: แท็กซี่ชมพู, แท็กซี่เขียวเหลือง, ตุ๊กตุ๊กมีคนขับ, วินมอไซค์, กระบะ, สองแถว, รถเมล์ สุ่มตามน้ำหนัก
- 2 เลน ชิดซ้ายแบบไทย รถชะลอ/หยุดเมื่อมีคันหน้า หายไปเมื่อสุดถนน (ถนนยาว ±30 ม.)
- Prefab รถอยู่ที่ `Assets/Prefabs/ThaiBoba/Traffic/`
- โมเดลรถ: `BlenderSource/thai_vehicles.py` (ถูกเรียกจาก `thai_boba_assets.py`) ตัวถังสร้างจากโปรไฟล์จริง (ฝากระโปรง กระจกเอียง ซุ้มล้อ ไฟหน้า-ท้ายโค้งรับมุม ป้ายทะเบียน)
  ล้อแยกชิ้น `Wheel_*` หมุนตามความเร็ว (`WheelSpin`) · จุด `Seat_*` ให้ใส่คนนั่ง (วิน, ตุ๊กตุ๊ก, ผู้โดยสารสองแถว)

- โมเดลคนสัดส่วนจริง: `BlenderSource/thai_npc.py` → `Assets/Models/ThaiBobaShop/Characters/NPC_*.fbx`
  ~8–9k tris, texture 1024px ต่อตัว (ผ้า/หน้า/ผม bake รวม + AO), มีกระดูก + อนิเมชัน `Walk` (สะโพกโยก ส้น-ปลายเท้า แขนแกว่งสวน) / `Idle`
  เสื้อผ้าเป็นชิ้นจริง (ชายเสื้อ แขนเสื้อ ปลายขากางเกง คอปก กระโปรงจีบ ผ้าถุง) · มือมีนิ้ว · รองเท้า/รองเท้าแตะ · ตา หู ผม (ม้า/บ็อบ/ยาว/หางม้า/มวย)
  ท่านั่งสำหรับรถ (`SEAT_*.fbx`): วินมอไซค์, คนขับตุ๊กตุ๊ก, ผู้โดยสารสองแถว 3 คน
  รันใหม่: `"D:\Bder\blender.exe" -b --factory-startup -P BlenderSource/thai_npc.py` (ใส่ `-- NPC_Office noexport` เพื่อดูตัวอย่างเร็วๆ)
- Animator Controller อยู่ที่ `Assets/Prefabs/ThaiBoba/Anim/` (พารามิเตอร์ `Speed`), `NPCAnimDriver` ส่งความเร็วจาก NavMeshAgent ให้อัตโนมัติ
- ลูกค้า (`Customer_ThaiBoba.prefab`) เปลี่ยนโมเดลตามประเภทลูกค้าอัตโนมัติ ส่วนคนเดินผ่าน (`Pedestrian_ThaiBoba.prefab`) สุ่มโมเดลแล้วเดินตามทางเท้า
- ร้านเปิด 07:00 (`Spawner.openHour`, `TimeCyc.startHour`) ลูกค้าคนแรกมาภายในไม่กี่วินาที

## บทสอนวันแรก (`TutorialSystem`)
- เริ่มเองในวันที่ 1 ของเกมใหม่ (ครั้งเดียว) · เล่นซ้ำได้จากเมนูหยุดเกม ▸ "เล่นบทสอนอีกครั้ง" · กด "ข้าม" ได้ตลอด
- 9 ขั้น: มองรอบๆ → รอลูกค้า → หยิบแก้ว → เทชา → ตักไข่มุก → ใส่น้ำแข็ง → ปรับความหวาน → ซีล → เสิร์ฟ
- ขั้นที่แสดงคำนวณจากของในแก้วจริงทุกเฟรม ใส่สลับลำดับได้ · ถ้าทำผิดจะบอกให้โยนแก้วทิ้งแล้วเริ่มใหม่
- ลูกศรเรืองแสง (`SM_TutorialArrow`) ลอยเหนือจุดที่ต้องไปต่อ
- ระหว่างบทสอน: มีลูกค้าคนเดียว ออเดอร์ง่าย (ชาไทย ไข่มุก 1 ช้อน ใส่น้ำแข็ง หวานมาก) · หลอดการรอไม่ลด · นาฬิกาหยุด

## ระบบเพิ่มเติม (เวอร์ชันหลัง 1.0.1)
- **ต้มไข่มุก** (`BobaPot`): หม้อว่างทุกเช้า · กดที่หม้อเพื่อต้ม (ใช้ไข่มุกดิบ 30 · 25 วิ) · สดราว 2.5 ชม.ในเกม แล้วแข็ง (ลูกค้าบ่น ไม่ได้ทิป)
- **ลูกค้าประจำ** (`RegularsSystem`): 6 คน มีชื่อ หน้าตา เมนูประจำ · สนิท 0–5 · ครบ 5 ให้ของขวัญ + สูตรลับ "อัญชันมะนาว"
- **ตกแต่ง & ขยายร้าน** (`DecorShop` · แท็บในคอมพิวเตอร์): ต้นไม้ ธงราว ไฟปิงปอง แมวกวัก ภาพผนัง ม้านั่ง · จ้างพนักงาน (ต้มไข่มุก/สั่งของให้ · 120 ฿/วัน) · ขยายไปตึกข้างๆ

## ระบบชุดใหม่: ซอยที่มีชีวิต
- **คิวลูกค้า** (`CustomerController` + `Spawner.queueSlots`): แถวรูปตัว L ชิดหน้าร้าน (ไม่ล้นลงถนน) เดินไปท้ายแถวก่อนค่อยเข้าคิว · เสิร์ฟแล้วออกทางขวาไม่ตัดแถว · ติดเกิน 4 วิ ค่อยกระโดดเข้าจุด (แทบไม่เกิด)
- **ท่าทาง NPC** (layer "Gestures" + `NPCAnimDriver`): เล่นมือถือ ดูนาฬิกา จิบชา โบกมือ ส่ายหัวโกรธ สับไก่ เขย่าแก้ว (มีของในมือ) · ทุกคลิปวนลูปไม่กระตุก · โมเดล LOD1 สำหรับระยะไกล (`SetupLods`)
- **ท็อปปิ้ง** (`SM_ToppingBar` ผนังขวา · `IngredientStation.Kind.Topping`): บุก (เลเวล 2) วุ้นใบเตย (3) พุดดิ้ง (4) แก้วละ 1 อย่าง · ลูกค้าแต่ละแบบชอบต่างกัน · บทสอนมีขั้น "+"
- **เดลิเวอรี่** (`DeliverySystem` · ต้องซื้ออัปเกรดเดลิเวอรี่): ออเดอร์แอป 2–3 แก้วมีเวลา → วางแก้วที่ซีลแล้วบนชั้นรับออเดอร์ (`PickupRack` ปลายเคาน์เตอร์ข้างเครื่องซีล) → ไรเดอร์ขี่มอไซค์มาจอด เดินมารับ จ่ายเงิน+ทิปตามเวลาที่เหลือ · ไม่ทัน = ยกเลิก ชื่อเสียงลดนิดหน่อย
- **ร้านคู่แข่ง** (`RivalShop`): เปิดฝั่งตรงข้ามวันที่ 8 (กลับมาอีก 3 สัปดาห์หลังแพ้) มีพวงหรีด ลูกโป่ง คิวของเขาเอง ดึงลูกค้าไปสูงสุด 40% · แก้วเป๊ะ/ลูกค้าประจำ/เดลิเวอรี่ทันเวลา = ดึงกลับ · ลูกค้าเดินหนี = เสียให้คู่แข่ง · โปรใบปลิว 300 ฿ (คอมพิวเตอร์ > พนักงาน & โปรโมชั่น) · ชนะ = โบนัส 500 ฿ + ชื่อเสียง + เหรียญ
- **พนักงานชงชาคนที่ 2** (`BaristaStaff`): จ้าง 2,500 ฿ ค่าแรง 150+30×เลเวล ฿/วัน · ชงให้ลูกค้าคนที่ 2 ในคิว (หรือคนหน้าสุดถ้าเราว่าง) · ฝึกฝีมือ 3 เลเวล (เร็วขึ้น เป๊ะขึ้น)
- **เทศกาลใหม่**: ตรุษจีน (วันที่ 29: โคมแดง จุดประทัด 9:00/18:00 ลูกค้าให้อั่งเปา) · วันแม่ (17: ธงฟ้า พวงมาลัยมะลิ ป้าๆ มาเยอะ) · เทศกาลกินเจ (19: ธงเหลือง ลูกค้า (เจ) ห้ามชีสโฟม/พุดดิ้ง) — `FestivalFX`
- **เพื่อนบ้าน** (`NeighbourStall`): ร้านข้าวมันไก่ข้างร้านเปิด 6:30–14:30 ม้วนเหล็กขึ้น-ลงเอง ลุงสับไก่มีเสียงมีด ช่วงเที่ยงมีไรเดอร์ยืนรอ ปิดแล้วคลุมผ้าใบ · **แมวจร** 3 ตัว (`StrayCat`) เดินเล่น นั่ง เลียขน นอน (นานตอนกลางคืน/เที่ยง) ร้องเหมียว ลูบได้
- **กลางคืน**: รถเปิดไฟหน้า มีแสงตกบนถนน ไฟท้ายแดง (`VehicleLights`) · คืนฝนตก ไฟเสา/ป้ายร้าน/ไฟรถสะท้อนเป็นเส้นบนถนนเปียก (`NightReflections`, `NightFX`)
- **ถนนเปียกสะท้อนจริง** (`PlanarReflection` + shader `ThaiBoba/WetReflection`): ตอนถนนเปียก กล้องตัวที่สองเรนเดอร์ภาพกลับหัวที่ระนาบถนน (ครึ่งความละเอียด ไม่มีเงา) แผ่นใสบนถนน/ทางเท้าสองฝั่งแสดงเงาสะท้อนตึก ป้าย ไฟ รถ คน และสายฝน มีวงกระเพื่อมจากหยดฝน · ปิดเองตอนกราฟิก "ต่ำ" และตอนถนนแห้ง
- **ฝนตกเฉพาะถนนกลางแจ้ง** (ระหว่างกันสาดสองฝั่ง) ไม่ทะลุหลังคาเข้าร้าน
- **เนื้อเรื่อง** (`StoryMode` · ชิปใต้การ์ดภารกิจ / เมนูหยุดเกม): 5 บท — จากรถเข็นสู่ห้องแถว → ขาประจำของซอย → ศึกชานมฝั่งตรงข้าม → ทีมของเรา → สาขาที่สอง (เปิดสาขา 2 ที่ตึกฝั่งตรงข้าม 12,000 ฿ แล้วได้กำไร +250 ฿ ทุกเย็น) · รถเข็นคันแรกจอดอยู่ปากซอย (`FirstCartMemento`)
- **จัดร้านเอง** (`DecorPlacement` · คอมพิวเตอร์ > ตกแต่ง > จัดร้านเอง): หยิบต้นไม้/ม้านั่ง/โต๊ะ/ป้ายโปร/โอ่งมังกร ย้ายและหมุน (ล้อเมาส์/R, ปุ่ม "หมุน" บนมือถือ) · วางบนคิวหรือทางออกไม่ได้ (วงแดง) · บันทึกในเซฟ
- **สถิติ & เหรียญรางวัล** (`StatsSystem` · เมนูหลัก/หยุดเกม): สถิติตลอดกาล + เหรียญ 20 แบบ เก็บแยกในไฟล์ `profile_stats.json` (ไม่หายตอนเริ่มเกมใหม่)
- **เสียงสังเคราะห์** (`ArtSource/Audio/synth_sfx.py` สคริปต์ Python ล้วน): เครื่องปั่น, แตรตุ๊กตุ๊ก 2 แบบ, แตรมอไซค์, เสียงตุ๊กตุ๊กวิ่งผ่าน, แมว, มีดสับ, ประทัด, เสียงแอปเด้ง, เขย่าแก้ว · เสียงคนคุยหน้าร้านดังตามความยาวคิว (`GameAudio.crowdPoint`) · `GameAudio.PlayAt` เล่นเสียง 3D

## วิธีทำเครื่องดื่ม
ใส่ไข่มุก / น้ำแข็ง / ชา / ความหวาน ลำดับไหนก็ได้ จนกว่าจะซีลฝา
หยิบแก้ว (แก้วซ้อน) → ไข่มุก (หม้อ, กดได้ 1–3 ครั้ง) → น้ำแข็ง (กระติก) → ความหวาน (ขวดไซรัป กดวน 0/25/50/100/120%) → เทชา (ถังชา/กระป๋องบนชั้น) → ซีล (เครื่องซีล) → เสิร์ฟ (เคาน์เตอร์)
ทำผิดทิ้งที่ถังขยะในร้าน

## ระบบที่เพิ่มให้เกมสนุกขึ้น
- **ลูกค้า 6 แบบ** นักเรียน / พนักงานออฟฟิศ / นักท่องเที่ยว / ป้าข้างบ้าน / ไรเดอร์ / รีวิวเวอร์ — ความอดทน, ทิป, รสที่ชอบ, ความหวาน และบทพูดไทยต่างกัน มาตามช่วงเวลา (เช้า-เที่ยง-เลิกเรียน)
- **คิว + ความอดทน** ลูกค้าต่อแถวหน้าร้าน รอนานเกิน → เดินหนี ชื่อเสียงลด
- **ให้คะแนนแก้ว** เป๊ะ = ได้ทิป + คอมโบ (สูงสุด +50%) / ผิดเล็กน้อย = ได้เงินไม่มีทิป / ผิดเมนูหรือยังไม่ซีล = ลูกค้าไม่รับ
- **ชื่อเสียง 0–5 ดาว** ยิ่งดังลูกค้ายิ่งเยอะ
- **เลเวลร้าน** ปลดล็อกเมนู: ชาไทย, ชานม → ชาเขียว → นมชมพู → เผือก → โกโก้ → แดงมะนาวโซดา
- **อีเวนต์ประจำวัน** ร้อนตับแตก, ฝนตกหนัก, เงินเดือนออก, สงกรานต์ (ทุก 10 วัน), ปิดเทอม, รีวิวเวอร์มาเยือน, ตลาดนัดหน้าร้าน
- **ไหว้ศาลพระภูมิ** วันละครั้ง 20 ฿ → ทิป +20% และลุ้นลูกค้าใจดี
- **อัปเกรดร้าน** ลำโพงลูกทุ่ง, พัดลม, โต๊ะ+เก้าอี้แดง, หม้อไข่มุกใหญ่, เครื่องซีลเทอร์โบ, ป้ายนีออน, เดลิเวอรี่ (อัปเกรดเปิดโมเดลในฉากให้เห็นจริง)
- **ภารกิจประจำวัน** 3 ภารกิจ มีรางวัลเงิน
- **สรุปปิดร้าน** ยอดขาย ทิป ค่าใช้จ่าย กำไรสุทธิ
- **ต้นทุนวัตถุดิบ** สั่งของต้องจ่ายเงิน (`ComputerTerminal.OrderCups10()` ฯลฯ)
- **Save** เก็บ เงิน วัน ดาว เลเวล อัปเกรด (เดิมไม่ได้เซฟเงิน/วัน — แก้แล้ว)
